# نظام نقاط البيع — حلواني السفير

نظام كاشير عربي متعدد الفروع لمحلات حلواني السفير. يحفظ الفواتير والمبيعات والشيفتات في MongoDB Atlas ويعمل من المتصفح على أجهزة الفروع.

## الوظائف الأساسية

- كاشير وفواتير حرارية 80 مم.
- فروع ومستخدمون بصلاحيات مالك وكاشير.
- مبيعات نقدي / فيزا / محفظة.
- سجل مبيعات منظم حسب يوم العمل والفرع والشيفت.
- ملخص يومي وتقارير محفوظة بعد قفل الشيفت.
- أصناف بالقطعة أو بالكيلو، ومنها قسم الشوكولاتة.

## مواعيد التشغيل

- يوم العمل: من **9:00 صباحًا** إلى **1:00 صباح اليوم التالي**.
- الشيفت الصباحي: من **9:00 صباحًا** إلى **6:00 مساءً**.
- الشيفت المسائي: من **6:00 مساءً** إلى **1:00 صباحًا**.
- أي مبيعات من 12:00 إلى 12:59 صباحًا تدخل ضمن يوم العمل السابق.

## بنية المشروع

```text
backend/   Express + MongoDB + JWT
frontend/  React + Vite
```

في الإنتاج يخدم الـBackend الواجهة والـAPI من نفس الدومين. لذلك لا توجد حاجة إلى رابط API منفصل.

## تشغيل محلي للتطوير

1. أنشئ `backend/.env` بالاعتماد على `backend/.env.example`.
2. ضع رابط MongoDB Atlas و`JWT_SECRET` قويًا في ملف البيئة.
3. شغّل الـBackend:

```bash
cd backend
npm install
npm run dev
```

4. في نافذة أخرى شغّل الواجهة:

```bash
cd frontend
npm install
npm run dev
```

## النشر على Hostinger

يتطلب النشر خطة **Business Web Hosting** أو **Cloud Hosting** تدعم Node.js.

- اربط مستودع GitHub من صفحة `Node.js Web App`.
- استخدم Node.js 22.
- `Build Command`: `npm run build`
- `Start Command`: `npm start`
- أضف متغيرات البيئة من لوحة Hostinger فقط:

```text
NODE_ENV=production
APP_TIMEZONE=Africa/Cairo
MONGO_URI=...
MONGO_DB_NAME=elsafeer_pos
JWT_SECRET=...
JWT_EXPIRES_IN=12h
CLIENT_URL=https://your-domain.example
```

لا تضع أي كلمات سر أو روابط MongoDB حقيقية في GitHub أو داخل ملفات المشروع.

## الأمان

- كلمات المرور تُشفّر قبل الحفظ.
- جميع الطلبات المحمية تستخدم JWT.
- الكاشير لا يستطيع الوصول إلى بيانات فرع آخر.
- سعر الصنف يُقرأ من قاعدة البيانات وقت البيع، ولا يُعتمد على السعر المرسل من المتصفح.
- لا تشغّل `npm run seed` على قاعدة بيانات الإنتاج؛ هذا الأمر مخصص للبيانات التجريبية فقط وقد يعيد ضبط البيانات.

## الطباعة

الطباعة تتم من نافذة المتصفح على الطابعة الحرارية المتصلة بجهاز الكاشير. استخدم طابعة XP-80 بمساحة طباعة 72 مم، واختر `Actual size` بدل `Fit to printable area`.
